변경 내용

Sealion Home과 Sealion Link의 공개 버전 변경 사항입니다.

Home 0.9.60 · Link 0.8.38 유지

2026.10.13 / 공개 베타

  • 차량에서 업데이트 설치 권한 설정 화면을 열 수 없을 때 ADB 권한 도우미로 연결합니다.
  • 설정의 업데이트 설치 허용에서 현재 앱의 설치 권한을 직접 확인하고 선택해 요청할 수 있습니다.
  • 권한은 Android 실제 상태를 확인하며 업데이트 파일의 서명 확인과 최종 설치 승인 절차를 유지합니다.
  • 기존 버전에서 설정 화면을 열 수 없다면 APK를 차량 파일 관리자에서 한 번 직접 업데이트하세요.
  • Sealion Link는 기존 0.8.38 버전을 그대로 사용합니다.

기존 배포용 앱을 삭제하지 않고 업데이트하세요. 차량 ADB는 먼저 켜고 이 앱의 연결을 직접 승인해야 합니다.

Home 0.9.59 · Link 0.8.38 유지

2026.10.13 / 공개 베타

  • 새 설치에서 왼쪽 후측방 카메라의 기울기 31도, 좌우 시선 -48도, 위아래 시선 10도를 기본으로 사용합니다.
  • 오른쪽 후측방 카메라는 기울기 -30도, 좌우 시선 50도, 위아래 시선 9도를 기본으로 사용합니다.
  • 양쪽 후측방 카메라에 좌우 반전, 어안 렌즈 평탄화 강도 1.00과 렌즈 추정 화각 190도를 기본 적용합니다.
  • 기존에 저장한 카메라 보정값은 유지하며 기본 구도 적용과 보정 초기화에서 새 기본값을 선택할 수 있습니다.
  • Sealion Link는 기존 0.8.38 버전을 그대로 사용합니다.

기존 배포용 앱을 삭제하지 않고 업데이트하세요. 새 기본값은 차량에서 방향을 지정한 카메라에 적용됩니다.

Link 0.8.38 · Home 0.9.58 유지

2026.10.13 / 공개 베타

  • 자동 잠금의 차량 신호만 사용 선택지를 제거하고 걸음 감지를 기본으로 적용했습니다.
  • 최근 45초 안에 걸음을 감지한 경우 차량 신호로 접근과 이탈을 확인합니다.
  • 이전 감지 방식 설정도 걸음 감지로 전환하며 자동 잠금 켜짐 상태와 거리 구간은 유지합니다.
  • 신체 활동 권한이나 걸음 센서에 문제가 있으면 필요한 확인 사항을 안내합니다.
  • Sealion Home는 기존 0.9.58 버전을 그대로 사용합니다.

기존 배포용 앱을 삭제하지 않고 업데이트하세요. 자동 잠금에는 휴대폰의 신체 활동 권한이 필요합니다.

Home 0.9.58 · Link 0.8.37 유지

2026.10.13 / 공개 베타

  • 차량에서 표준 Android 권한 설정 화면을 열 수 없을 때 실제 차량 앱 권한 화면으로 연결합니다.
  • 다른 앱 위에 표시와 음악 알림 접근을 선택해 설정하는 차량 ADB 권한 도우미를 추가했습니다.
  • 권한 도우미는 사용자가 선택하고 확인한 권한만 요청하며, 실제 허용 상태를 다시 읽어 결과를 표시합니다.
  • 권한 설정을 중지하거나 다른 화면으로 이동하면 진행 중인 요청을 취소합니다.
  • 일반 권한과 두 가지 선택 권한의 상태를 구분해 처음 설정 안내를 보완했습니다.
  • Sealion Link는 기존 0.8.37 버전을 그대로 사용합니다.

기존 배포용 앱을 삭제하지 않고 업데이트하세요. ADB 권한 도우미는 차량 ADB를 켜고 앱의 연결을 직접 승인한 상태에서 사용합니다. 차량이 권한 변경을 제한하면 허용 완료로 표시하지 않습니다.

Home 0.9.57 · Link 0.8.37 유지

2026.10.13 / 공개 베타

  • 계기판을 직접 켜면 상시 후방캠 설정에 따라 카메라 연결도 시작합니다.
  • 처음 영상을 받기 전 일시적인 통신 오류는 제한적으로 자동 재시도합니다. 중지·화면 OFF·다른 카메라 기능 사용 중에는 해당 요청을 취소합니다.
  • 계기판 화면에서 카메라 권한, 방향 연결과 실제 영상 수신 상태를 확인하고 다시 연결할 수 있습니다.
  • 권한 요청 중 화면 회전·다른 화면 이동 후에도 요청을 이어가며, OFF 또는 중지하면 이전 요청을 취소합니다.
  • 네이버지도 계기판 전송 코드와 메뉴를 제거했습니다. 차량 화면의 일반 내비 앱 실행은 유지합니다.
  • Sealion Link는 기존 0.8.37을 그대로 사용합니다.

같은 배포용 앱을 삭제하지 않고 업데이트하세요. 차량의 실제 카메라 접근과 계기판 영상 출력은 차량 펌웨어·권한·방향 지정에 따라 확인이 필요합니다.

Home 0.9.56 · Link 0.8.37

2026.10.13 / 공개 베타

  • 공개 버전의 메뉴를 사용 목적에 맞게 정리했습니다. 수동 카메라 명령과 개발용 진단은 개발자용에서만 표시합니다.
  • Sealion Home 첫 실행 시 차량 연결, 권한과 기본 홈 선택을 안내하는 설정 화면을 추가했습니다.
  • 공조·시트·바람 방향을 공조 메뉴에 모으고 차량 메뉴와 설정의 중복 항목을 정리했습니다.
  • Sealion Link의 공개 메뉴와 상태 안내를 간단하게 정리하고 연결 설정을 쉽게 찾을 수 있도록 바꿨습니다.
  • 네이버 지도 계기판 표시 기능을 제거했습니다. 차량 화면에서 내비게이션 앱을 실행하는 기능은 유지합니다.
  • 공개 업데이트 주소를 연결했습니다. 앱 실행 시 새 버전을 확인하고 파일·앱 ID·버전·서명 검사를 거쳐 Android 설치 화면으로 안내합니다.
  • 개발자용과 공개 배포용을 함께 설치할 수 있으며 선택한 기본 홈을 서로 바꾸지 않도록 했습니다.

주소 연결 전 준비용 APK를 쓰고 있다면 처음 한 번은 이 사이트의 APK를 직접 설치해 주세요. 같은 배포용 앱을 삭제하지 않고 업데이트하면 설정을 유지하며 이후 버전은 앱에서 안내합니다.

차량에서 확인이 필요한 기능

시동 OFF 후 녹화·원격 영상 보기, 기본 홈 유지, 앞차 출발 알림과 주차 거리 센서는 차량 전원 정책, 펌웨어와 SDK 신호에 따라 달라집니다. 코드 검사와 APK 빌드가 해당 차량의 동작 확인을 대신하지는 않습니다.

설정 유지

같은 배포용 앱을 삭제하지 않고 업데이트하면 설정을 유지합니다. 개발자용과 배포용의 설정은 별도로 저장됩니다.
