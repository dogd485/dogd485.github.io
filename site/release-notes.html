변경 내용

Sealion Home과 Sealion Link의 공개 버전 변경 사항입니다.

Home 0.9.56 · Link 0.8.37

2026.10.13 / 공개 베타

  • 공개 버전의 메뉴를 사용 목적에 맞게 정리했습니다. 수동 카메라 명령과 개발용 진단은 개발자용에서만 표시합니다.
  • Sealion Home 첫 실행 시 차량 연결, 권한과 기본 홈 선택을 안내하는 설정 화면을 추가했습니다.
  • 공조·시트·바람 방향을 공조 메뉴에 모으고 차량 메뉴와 설정의 중복 항목을 정리했습니다.
  • Sealion Link의 공개 메뉴와 상태 안내를 간단하게 정리하고 연결 설정을 쉽게 찾을 수 있도록 바꿨습니다.
  • 네이버 지도 계기판 표시 기능을 제거했습니다. 차량 화면에서 내비게이션 앱을 실행하는 기능은 유지합니다.
  • 공개 업데이트 주소를 연결했습니다. 앱 실행 시 새 버전을 확인하고 파일·앱 ID·버전·서명 검사를 거쳐 Android 설치 화면으로 안내합니다.
  • 개발자용과 공개 배포용을 함께 설치할 수 있으며 선택한 기본 홈을 서로 바꾸지 않도록 했습니다.

주소 연결 전 준비용 APK를 쓰고 있다면 처음 한 번은 이 사이트의 APK를 직접 설치해 주세요. 같은 배포용 앱을 삭제하지 않고 업데이트하면 설정을 유지하며 이후 버전은 앱에서 안내합니다.

차량에서 확인이 필요한 기능

시동 OFF 후 녹화·원격 영상 보기, 기본 홈 유지, 앞차 출발 알림과 주차 거리 센서는 차량 전원 정책, 펌웨어와 SDK 신호에 따라 달라집니다. 코드 검사와 APK 빌드가 해당 차량의 동작 확인을 대신하지는 않습니다.

설정 유지

같은 배포용 앱을 삭제하지 않고 업데이트하면 설정을 유지합니다. 개발자용과 배포용의 설정은 별도로 저장됩니다.
