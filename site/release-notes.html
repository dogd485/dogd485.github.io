변경 내용

Sealion Home과 Sealion Link의 공개 버전 변경 사항입니다.

Home 0.9.74 · Link 0.8.44 유지

2026.10.14 / 공개 베타

  • Home 0.9.74: 계기판의 카메라 영상을 중앙 표시 영역에 배치해 순정 상·하단 표시가 차 그림과 거리 숫자를 가리지 않도록 수정했습니다. 탑뷰 32% · 후방 영상 68% 배치는 유지합니다.
  • 탑뷰에서 앞뒤 보기 범위를 강제로 줄이던 확대를 제거했습니다. 저장한 앞뒤 보기 범위가 실제 표시 범위에 적용되며 설정에서 각각 조절할 수 있습니다.
  • ‘탑뷰 기본값 적용 · 네 방향’ 버튼을 미리보기 위에 고정하고 현재 네 방향의 렌즈 보정 종류·높이·각도와 미저장 상태를 표시합니다. 기존 저장 보정값은 자동으로 덮어쓰지 않습니다.
  • 평평한 바닥의 실제 주차선과 네 방향 영상을 확인한 뒤 설정을 저장해 주세요. 실차의 주차선 이음새 정합은 추가 확인이 필요합니다. 이전 버전의 업데이트 설치 대체 경로와 Link 0.8.44는 유지합니다.

Home 0.9.73 · Link 0.8.44 유지

2026.10.14 / 공개 베타

  • Home 0.9.73: 설치 권한을 허용했는데도 APK 설치 화면이 열리지 않는 차량을 위해 설치 전용 동작과 Android 설치 세션 대체 경로를 추가했습니다. 최종 설치는 Android 확인 화면에서 직접 승인합니다.
  • 설치 세션을 준비하기 전에 서명된 업데이트 정보와 APK의 앱 ID·버전·서명·크기·해시를 다시 검사합니다. 설치 준비·승인 대기·실패 원인을 구분해서 표시합니다.
  • 현재 설치된 구버전에서 설치 화면이 열리지 않으면 이번 APK는 기존에 사용하던 파일 관리자 또는 ADB 설치 방식으로 한 번 직접 설치해야 합니다. 같은 종류의 앱을 삭제하지 않고 업데이트해 주세요.
  • 카메라·계기판 어라운드뷰·화면 공유 설정과 Link 0.8.44는 유지합니다. 실제 차량의 Android 설치 확인 화면 지원은 실차 확인이 필요합니다.

Home 0.9.72 · Link 0.8.44 유지

2026.10.14 / 공개 베타

  • Home 0.9.72: 계기판 어라운드뷰에 자체 제작한 흰색 차량 그림을 추가하고 탑뷰 32% · 후방 68% 배치와 가까운 앞뒤 보기로 탑뷰를 확대했습니다. 기존 카메라 연결·각도·렌즈 보정값은 유지합니다.
  • 후진 화면의 거리 표시에서 위치 이름을 제거하고 숫자만 표시합니다. 단위가 확인된 센서만 cm를 표시하며 계기판 하단에 가리지 않도록 여백을 조정했습니다.
  • Android 공유 승인 화면이 없는 차량에 명시적으로 시작하는 차량 ADB 화면 공유 경로를 추가했습니다. 기존 승인된 연결로 센터 내비를 유지하며 최대 초당 2회 갱신합니다. 후진·방향지시등 카메라 중에는 공유 캡처를 쉽니다.
  • 실제 차량의 ADB 화면 캡처 지원과 계기판 출력은 실차 확인이 필요합니다. Link 0.8.44는 그대로 유지합니다.

Home 0.9.71 · Link 0.8.44 유지

2026.10.14 / 공개 베타

  • Home 0.9.71: 차량 원본 네 방향 카메라의 탑뷰 기본 각도·위치·높이와 카메라별 렌즈 보정 프로필을 추가했습니다. 새로 연결하는 지원 원본 카메라에 사용하며 실제 미리보기 확인이 필요합니다.
  • 어라운드뷰의 ‘탑뷰 기본값 적용 · 네 방향’에서 기본 프로필을 불러올 수 있습니다. 기존에 저장한 값은 자동으로 덮어쓰지 않으며 미리보기를 확인하고 저장해야 변경됩니다.
  • 카메라별 초점거리·중심·왜곡 계수를 사용하는 지면 투영을 추가했습니다. 기존에 저장한 어안 보정 방식도 유지합니다. 차량별 광학 차이와 바닥 위 물체의 늘어남·합성 경계는 실차에서 확인이 필요합니다.
  • 일반 원본 카메라의 앞·뒤·좌·우 시선 기본 각도는 수평 0도로, 좌우 카메라의 기본 반전은 켜짐으로 설정했습니다. ‘방향별 기본 각도 적용’으로 현재 방향에 적용하고 저장할 수 있습니다. 기존 보정값은 유지합니다.
  • Sealion Link 배포용 0.8.44는 그대로 유지합니다.

  • 이전 버전의 주차 녹화 재연결과 자동 잠금 설정 유지 수정을 포함합니다. 같은 개발용 또는 배포용 앱을 삭제하지 않고 업데이트하세요.
