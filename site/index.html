GET READY / 설치 안내

시작은 세 단계.

설치할 기기를 고르고, 순서대로 따라오세요.

1

차량용 파일 받기

Sealion Home APK를 내려받아 USB나 차량에서 접근할 수 있는 경로로 옮기세요.

2

설치 허용 후 실행

차량 파일 관리자에서 APK를 열고, Android 안내에 따라 해당 앱의 설치 권한을 허용하세요.

3

차량 연결 확인

처음 실행하면 차량 연결 안내가 열립니다. 권한과 연결 상태를 확인하고 기본 홈을 선택하세요. 기본 홈 변경은 차량 펌웨어가 허용해야 합니다.

1

휴대폰용 파일 받기

Android 휴대폰에서 Sealion Link APK를 내려받으세요. iPhone용 앱은 제공하지 않습니다.

2

Android 설치 승인

다운로드한 파일을 열고 브라우저나 파일 관리자의 ‘알 수 없는 앱 설치’를 허용하세요.

3

내 차 연결 등록

앱 안내에 따라 차량을 등록하고 Bluetooth·근처 기기 권한과 백그라운드 실행을 확인하세요.

AND THEN, UPDATE.

그다음은 앱에서.

공개 버전은 앱을 열 때 새 버전을 확인하고, 다운로드 후 Android 설치 화면으로 안내합니다. 설치 승인은 Android 화면에서 직접 선택합니다. 설정을 유지하려면 앱을 삭제하지 말고 업데이트하세요.

BEFORE YOU START

먼저 확인하세요.

01사용 가능한 차량과 휴대폰+

SEALION 7의 Android 차량 디스플레이를 기준으로 개발하고 있습니다. 최소 Android 버전은 11입니다. 차량 펌웨어, SDK와 권한에 따라 지원 기능이 달라집니다. Sealion Link는 Android 휴대폰 전용입니다.

02순정 런처 대신 기본 홈으로 사용하기+

차량에서 기본 홈 앱 변경을 허용해야 합니다. 설정에서 기본 런처 설정·유지를 시도할 수 있지만, 차량 펌웨어 정책에 따라 적용되지 않을 수 있습니다.

03시동 OFF 카메라·주차 녹화+

카메라·본체 전원과 네트워크가 유지되고 차량이 관련 권한을 제공해야 합니다. 현재 시동 OFF 녹화와 원격 영상을 보장하지 않습니다. 공개 차량용에서는 재배포 권한이 확인되지 않은 캡처 모듈을 제외했으며, 직접 카메라 연결 지원 여부는 실차 확인이 필요합니다.

04주차 센서·앞차 출발 알림+

차량에서 거리 값과 출발 안내 신호를 제공해야 합니다. 신호가 수신되지 않으면 거리나 알림을 임의로 만들지 않습니다. 현재 차량별 신호 수신 확인이 필요한 기능입니다.

05업데이트와 설정 유지+

같은 배포용 앱을 삭제하지 않고 업데이트하면 설정을 유지합니다. 개발자용과 배포용은 별개의 앱으로 설정을 공유하지 않습니다. 앱 삭제 또는 앱 데이터 삭제 시에는 다시 설정해야 합니다. 이 사이트의 공개 버전은 앱 실행 시 새 버전을 확인합니다. 주소 연결 전 준비용 버전을 쓰고 있다면 처음 한 번은 이 사이트의 APK로 직접 업데이트하세요.

06회원가입과 개인정보+

공개 APK 다운로드에는 사이트 회원가입이 필요 없습니다. 이 사이트에는 광고·분석 추적 스크립트를 넣지 않았습니다. 차량 계정이 필요한 제어 기능은 앱에서 별도로 연결합니다. 자세한 내용은 개인정보 안내를 확인하세요.
