개인정보 안내

다운로드 사이트와 앱의 연결 기능을 구분해 안내합니다.

다운로드 사이트

사이트 회원가입이나 로그인 없이 공개 APK를 내려받을 수 있습니다. 문의·계정 입력 폼, 광고와 방문 분석 스크립트를 넣지 않았습니다. 앱 다운로드 파일이나 업데이트 정보에 접근할 때 호스팅 서비스는 접속 정보를 처리할 수 있습니다.

앱 업데이트 확인

설치된 앱은 설정된 업데이트 주소에서 공개 버전 정보를 읽습니다. 차량 계정, PIN, 위치나 녹화 파일을 업데이트 확인 요청에 넣지 않습니다. APK 다운로드와 새 버전 정보 요청에 필요한 인터넷 연결을 사용합니다.

차량 계정과 기기 권한

차량 계정이 필요한 제어 기능과 Bluetooth 자동 잠금은 앱 내 연결 설정에서 구성합니다. 사용하는 기능에 따라 Bluetooth·근처 기기, 위치·활동 감지, 백그라운드 실행, 저장소, 카메라 또는 차량 연결 권한이 필요할 수 있습니다. Android와 차량의 권한 화면에서 허용 여부를 선택합니다.

원격 연결

원격 연결을 설정하는 경우 선택한 연결 서비스와 차량·휴대폰 네트워크를 사용합니다. 해당 서비스의 계정과 개인정보 처리 조건은 연결 과정에서 별도로 확인하세요.

저장된 설정과 영상

앱 설정과 최근 동작 기록은 기기에 저장됩니다. 녹화 기능을 사용하면 선택한 저장 위치에 영상이 저장됩니다. 앱 데이터 삭제, 앱 제거 또는 영상 삭제 전에는 보관할 내용을 확인하세요.
